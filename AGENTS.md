# AGENTS.md — вводная для любого ИИ-ассистента / новой среды разработки

Прочитай этот файл первым, затем `docs/`. Здесь всё, что нужно, чтобы продолжить работу без истории чата.

## Что это
Хоррор-мод для Minecraft **Forge 1.20.1** (Forge 47.4.10, Java 17, official mappings).
**Название мода: «The 1758645414»** (решение пользователя, 2026-10-08). Mod id: `anta` (внутренний, не менять — от него зависят id сущности, команды `/anta`, ключи сохранений). Пакет: `com.anta`.
Jar: `the1758645414-forge-1.20.1-<версия>.jar`. Настройки в игре: `config/the1758645414-common.toml` (`AntaConfig.java`).
Суть: антагонист («Наблюдатель») выглядывает из-за угла, наклоняясь вбок. Когда игрок смотрит на него — прячется. Никогда не нападает, только смотрит. Цель — паранойя.
Готовится публикация на CurseForge и Modrinth: тексты и чек-лист — `docs/release/` (там же правила площадок и риск Modrinth по ИИ-коду).

## Команды сборки (Windows, из корня проекта)
```
gradlew.bat build        # собрать jar в build/libs/
gradlew.bat runClient    # запустить игру с модом
```
Первая сборка долгая (скачивает и декомпилирует Minecraft, нужно ~3 ГБ RAM).

## Правила работы
- Общаться **по-русски**. Пользователь не программист: объяснять простым языком, без жаргона.
- Все версии плана (1–5) и все идеи банка сделаны (3.6.0), 4.0.0 — релизная после полного ревью. Вид трупов (`CarcassLayout`, текстуры `tools/gen_blood.py`) менять только через симулятор `tools/animsim/sim_carcass.ps1` и смотреть кадры (`tools/animsim/out/carcass_*.png`, крупно: `python carcass_render.py --big out/carcass_<kind>_<style>.json DETAIL`) до выпуска. Без звуков, кроме шагов и шороха позади в лесу (4.4.0, `docs/SOUNDS.md`); криков и голоса не добавлять. Новое — только по решению пользователя; сначала протестировать и зафиксировать.
- После изменений: **поднять версию** (`mod_version` в `gradle.properties`), дописать раздел в `docs/CHANGELOG.md` простым языком (для площадок — ещё `docs/release/CHANGELOG_EN.md`), затем запустить `powershell -ExecutionPolicy Bypass -File tools\release.ps1 -LowMemory` — он собирает мод и кладёт `the1758645414-forge-1.20.1-<версия>.jar` и `ИЗМЕНЕНИЯ.md` в папку `%USERPROFILE%\OneDrive\Desktop\Anta - версии`. Одна версия публикуется один раз (скрипт откажет, если такая уже есть). Затем обновить `docs/PLAN.md` (раздел «Текущий статус»).
- Правила для релиза (не ломать): отладочные сообщения по умолчанию выключены и только для операторов (`Director.say`/`debugFor`); всё, что забирает или открывает чужое (факел, дверь, деревня), — только через `Director.worldChangesAllowed`; никакой сети, телеметрии и записи файлов, кроме конфига и SavedData; личные данные («он знает о тебе») — только на клиенте и не в чат (чат пишется в лог); перед чтением блоков вне игрока — `level.isLoaded`; новые блок-состояния читать только после `hasProperty`/`instanceof`.
- Звуков в моде нет (решение пользователя, 2026-10-08) — ни голосов, ни эффектов. `tools/gen_sounds.py` и `audio/` — только архив. ElevenLabs-ключ (`ELEVENLABS_API_KEY`) не записывать в файлы проекта.
- Логику ИИ/спавна держать на сервере; клиентский код — только в `com.anta.client` (иначе мод упадёт на сервере).
- Анимации: **все анимации делать и проверять через симулятор** (решение пользователя). Всю математику (углы, кривые, тайминги) писать в `com.anta.anim.WatcherPose` (без импортов Minecraft), `WatcherModel` только применяет результат. Перед выпуском версии с анимацией — прогнать `powershell -ExecutionPolicy Bypass -File tools\animsim\sim.ps1 <сценарий>`, посмотреть `tools/animsim/out/<сценарий>_sheet.png` (сначала вид «FIRST PERSON» — это экран игрока); новые сценарии добавлять в `tools/animsim/SimMain.java`. Нужны Java 17 (`javac`) и Python с numpy + Pillow.
- Не коммитить и не пушить в git без разрешения пользователя.
