**Решение пользователя (2026-10-08): публикуем только на CurseForge.** Modrinth — нет: по их правилу 6.2.2 проекты, сделанные в основном ИИ, публиковать нельзя (подробности — внизу, если когда-нибудь передумаете).

Правила прочитаны 2026-10-08: [CurseForge Moderation Policies](https://support.curseforge.com/en/support/solutions/articles/9000197279-project-moderation-policies) (обновлены 08.09.2026). Запрета на код от ИИ там нет; есть только требование помечать скриншоты, изменённые ИИ, если они могут ввести в заблуждение. Наши скриншоты — настоящие, из игры.

## Проверка в игре перед загрузкой
Новый мир, читы включены, `/anta debug on`.
1. `/anta test` и `/anta test any` — выглядывает, прячется от взгляда; сквозь него можно ставить блоки.
2. `/anta director now` и отвернуться — появляется сам.
3. В пещере: `/anta test cave`, `/anta traces both` — следы только среди камня, не в базе.
4. `/anta test mirror` — ваш скин, голова пустая.
5. `/anta finale` и обернуться — его нет (без эффектов).
6. `/anta presence` — открылась дверь неподалёку.
7. В деревне: `/anta village` — жители пропали; через игровой день вернулись.
8. `/anta deadworld start` — все существа пропали, серый туман; `/anta deadworld stop` — все вернулись на места.
9. Нижний мир: `/anta test cave` и `/anta traces both` должны отказать.
10. Закрыть мир, открыть другой — нет серых сообщений, пока не введёте `/anta debug on`.
11. Если есть возможность: запустить выделенный сервер (`server.jar` + Forge) с модом — он не должен вылетать при старте.
