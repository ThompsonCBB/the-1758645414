# План тестов 4.6.2 (перед загрузкой на CurseForge)

С 3.4.0 в игре не проверено ничего. Этот план покрывает всё, что изменилось с тех пор.
Результаты: ставить [x] / писать, что не так, прямо здесь или в чат; итог — в `docs/PLAN.md` → «Текущий статус».

## Подготовка
- [ ] Закрыть KiroCrew, второй Kiro, лишние вкладки Brave (памяти мало).
- [ ] В `mods` только `the1758645414-forge-1.20.1-4.6.2.jar` (старые jar удалить).
- [ ] Лаунчер, Forge 1.20.1 (47.x), игре выделено 4 ГБ.
- [ ] **Отдельный тестовый мир**, творческий или выживание, читы включены. Деревня рядом со спавном — удобно.
- [ ] `/anta debug on`. Если что-то пошло не так — скриншот чата + `logs/latest.log`.

## Блок 1. Запуск (5 мин)
- [ ] Игра запускается, в меню Mods мод называется «The 1758645414», версия 4.6.2.
- [ ] Мир создаётся без вылета.
- [ ] После входа появился `config/the1758645414-common.toml`.

## Блок 2. Основа — укрытие и реакция (10 мин)
- [ ] `/anta test any` за деревом: ждёт ~0,5 с, медленно выглядывает (~1,5 с).
- [ ] Посмотреть в голову → резкий рывок назад и исчезает.
- [ ] `/anta react off`, `/anta test any`, походить вокруг: голова следит с задержкой, иногда наклоняется набок, тело неподвижно. Потом `/anta react on`.
- [ ] Сквозь него можно ставить блоки и стрелять; поводок и бирка не цепляются.
- [ ] «Мозги» — `/anta react stare`, затем `/anta test any` и посмотреть в голову: смотрит в ответ 1–2 с, потом прячется. Повторить и отвернуться посреди взгляда → когда повернётесь, его нет.
- [ ] `/anta react slow` → спокойно уходит за укрытие за 1,5 с, без рывка.
- [ ] `/anta react wait` → не реагирует, пока смотрите; отвели взгляд — пропал.
- [ ] `/anta react return` → дёрнулся назад, через 2–5 с снова выглянул из-за того же угла; второй взгляд — прячется насовсем.
- [ ] `/anta react random` → обычная игра; несколько `/anta test any` подряд — реакции разные.
- [ ] `/anta test` на ровном поле → «No cover found» (там ему негде стоять).
- [ ] `/anta test mirror` → он в вашем скине, голова пустая.

## Блок 3. «Режиссёр» (10 мин)
- [ ] `/anta director` показывает статус и сколько раз его заметили.
- [ ] `/anta director now`, отвернуться → появляется сам, вне поля зрения.
- [ ] Если не смотреть — через 20–40 с уходит.
- [ ] Просто поиграть 5–10 минут с `/anta debug off`: не слишком часто / не слишком редко?

## Блок 4. Пещеры (15 мин)
- [ ] Встать в туннеле лицом к повороту, `/anta test cave`, идти вперёд → мелькает из-за угла. Если «No ambush spot» — скриншот с цифрами.
- [ ] `/anta traces trail` → цепочка факелов **на стене на уровне головы, с одной стороны, через 7–11 блоков**, уходит вглубь.
- [ ] `/anta traces camp` → сундук + печка + факел, в сундуке хлам шахтёра, в печке еда.
- [ ] `/anta traces both` → факелы ведут к стоянке.
- [ ] Следы не появляются в вашей освещённой базе и в туннелях, которые вы вырыли сами.
- [ ] Вырыть свой туннель, `/anta mine` → мод его запомнил.

## Блок 5. События (15 мин)
- [ ] `/anta presence` → неподалёку открылась деревянная дверь (беззвучно). **Факелы не пропадают.**
- [ ] `/anta finale`, обернуться → он стоит за спиной и исчезает, **без слепоты и замедления**.
- [ ] Финал не срабатывает в воде, в лаве и в падении.
- [ ] Чат: **никаких** строчек от «???», табличек с ником, имени Windows.

## Блок 6. Деревня на один день (15 мин) — самое рискованное
- [ ] Перед тестом запомнить 1–2 жителей со сделками (скриншот торговли) и одно животное.
- [ ] Стоя в деревне, `/anta village` → жители, голем, животные исчезли. Дома и сундуки на месте.
- [ ] Животные с именем, на поводке, приручённые, осёдланные — **не пропали**.
- [ ] `/time add 24000` (или проспать) → все вернулись на свои места.
- [ ] Сделки у жителей те же, что до события.
- [ ] **Выход посреди события:** снова `/anta village`, выйти в меню, зайти → через день все вернулись, никто не задвоился.

## Блок 7. Мёртвый мир (15 мин) — новая система
- [ ] `/anta deadworld start` → пропали все существа (мобы, животные, жители), серый туман средней густоты, серое небо.
- [ ] Во время события ничего не спавнится, даже ночью; Наблюдатель тоже не появляется (`/anta director now`).
- [ ] Туман не слишком густой / не слишком слабый? (скриншот)
- [ ] `/anta deadworld stop` → все вернулись на свои места, туман ушёл.
- [ ] **Выход посреди события:** `start`, выйти из мира, зайти → туман и пустота сохранились; `stop` → все вернулись, без дублей.
- [ ] Естественное окончание: `start`, затем `/time add 24000` → событие закончилось само.

## Блок 7б. Что-то в лесу (10 мин)
- [ ] `/anta carcass sheep`, `cow`, `pig`, `chicken` — каждый лежит на боку, голова отдельно рядом, лужа под шеей. Не висит в воздухе, не утоплен в землю? (скриншот каждого)
- [ ] 4.5.0: для каждого животного все 4 вида — `/anta carcass cow decapitated`, `gutted`, `scattered`, `dragged` (и так же sheep, pig, chicken). Куски не висят в воздухе и не утоплены? Кишки видны, а не спрятаны под ногами? (скриншоты)
- [ ] Достаточно ли жутко?
- [ ] `/anta sound steps` и `/anta sound rustle` — звук за спиной; повернуть голову во время звука — он переходит. Громкость нормальная?
- [ ] Включить звук и сразу побежать — громкость и сторона не меняются.
- [ ] Встать в лесу, `/anta forest` — шаги/шорох сзади, в чате координаты; обернуться и дойти — там труп среди деревьев.
- [ ] Походить по лесу 10 минут с `/anta debug on` — сзади иногда слышно шаги/шорох («forest: sound behind you»). Не слишком часто?
- [ ] Ударить труп, поставить сквозь него блок — ничего не происходит. Перезайти в мир — трупы на месте.
