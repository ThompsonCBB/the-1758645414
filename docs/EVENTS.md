# События и особенности (3.6.0, поправлено в 4.0.0)

Все идеи из `IDEAS.md`, взятые в 3.6.0. Все числа — в `config/theonlooker-common.toml` (`AntaConfig.java`).

| Что | Код | Как работает |
|---|---|---|
| «Ближе, чем был» | `Director.preferredDistance` + `CoverFinder.find(..., preferredDist)` | 16 − 1 × (появлений за сессию), не меньше 8. Кольцо поиска расширяется внутрь до `preferred − 3` (не меньше 5) |
| Следы присутствия | `director/Presence.java` | Когда наблюдатель исчез, шанс 30 %: табличка (ник игрока, вощёная) на его месте / открыть закрытую деревянную дверь (только настоящие `DoorBlock` со свойствами HALF/OPEN, без звука) / убрать факел (без дропа). Радиус 20, ±5 по высоте, только невидимое игроку; видимость проверяется лениво, не больше 40 кандидатов. Дверь и факел — только если `Director.worldChangesAllowed` |
| Отражение | `WatcherEntity.MIRROR`, `WatcherRenderer.render` | 30 %. Два прохода рендера: тело — скин смотрящего игрока (тонкая модель для «slim»-скинов), голова — пустая `watcher_double` |
| Финал | `Director.tryFinale`, `WatcherEntity.finale` | После 8 замеченных (сохраняется с игроком), 10 % на появление, один раз на игрока (`anta_finale_done`). Не бывает, если игрок в воде/лаве, горит, едет, летит на элитрах или не стоит на земле; место без жидкости. Стоит в 1,2–2,2 блоках за спиной. Взгляд ≤45° — слепота 50 тиков + замедление, исчезает. Не обернулись за 60 с — уходит |
| «Он знает о тебе» | `client/KnowsYou.java`, `lang/*.json` | Только клиент. После того как замеченный наблюдатель исчез: шанс 35 %, не чаще раза в 6 мин, каждая фраза раз за игру. Показ — над хотбаром (`setOverlayMessage`), **не в чате**: чат пишется в `logs/latest.log`. Данные: `user.name`, часы ПК (только 0–5 ч), время сессии (≥1 ч), страна из `Locale.getDefault()`, имя мира (одиночная игра). Ничего не отправляется и не сохраняется. Город не делаем (нужен интернет) |
| Своя шахта | `director/MineMemory.java` (SavedData `anta_mine`) | Только измерения с небом (Верхний мир). Сломанные игроком (не `FakePlayer`) блоки на 4+ ниже поверхности, по ячейкам 8×8×8; ≥6 — «туннель». Вернулся после 4+ мин вне туннелей — «Режиссёр» появляется сразу |
| Деревня опустела | `director/VillageEvent.java` | `PlayerWakeUpEvent`, утро после сна, ≥5 замеченных, один раз на игрока (`anta_village_done`), кровать внутри **сгенерированной деревни** (`StructureTags.VILLAGE`). Убирает только существ внутри границ этой деревни (+8 блоков): жителей, железных големов и (настройка `emptyVillageAnimals`) животных; щадит именованных, на поводке, приручённых, осёдланных/с седоком. Только если `worldChangesAllowed` |
| Мультиплеер | `WatcherEntity.VIEWER`, `isFor`, `WatcherRenderer.shouldRender` | Наблюдатель «Режиссёра» помечается своим игроком ещё до появления в мире: остальным не рисуется и на них не реагирует. Отладочные `/anta test` — для всех |
| Изменения общего мира | `Director.worldChangesAllowed` | Дверь, факел, деревня — только в одиночной игре (не выделенный сервер и онлайн ≤1), иначе нужна настройка `worldChangesInMultiplayer = true` |
| Задержка головы | `WatcherPose.followHead` | Мёртвая зона 6°, потом догоняет с постоянной 4 тика. Симулятор: `sim.ps1 follow` |
| Наклон головы набок | `WatcherPose.idleTilt` | Слоты по 120 тиков, в ~половине — наклон 9–16° (18 тиков вход, 50 держит, 22 выход). Только голова. Симулятор: `sim.ps1 idle` |

Замеченные появления (`anta_sightings`) хранятся с игроком и переживают смерть и перезаход.

## Защита (4.0.0)
- Наблюдатель: `isPickable=false` (не мешает целиться, стрелы пролетают, бирки не работают), `canBeLeashed=false`, `mobInteract=PASS`, не толкается жидкостью.
- Нижний мир и Энд (нет неба): `Director.inCave` всегда false, `CaveTraces.place` и `MineMemory` не работают.
- Следы в пещерах: вокруг каждой клетки (радиус 2) только природные блоки (`CaveTraces.isNatural`), без блок-сущностей, не в вырытых игроком туннелях.
- Ни один поиск не подгружает чанки (`isLoaded` перед чтением блоков). `CoverFinder` — бюджет 20 мс, столбики в случайном порядке.
- Ошибки в следах/деревне ловятся и пишутся в лог, сервер не падает.
- Переключатели команд сбрасываются при старте сервера/мира (`ServerStartingEvent`).
- Отладочные сообщения: по умолчанию выключены (`debugMessages`), видны только операторам (`Director.debugFor`).


## Что-то в лесу (4.3.0)
`director/ForestKills.java`, сущность `entity/CarcassEntity.java`, рисунок `client/CarcassRenderer.java`, крик `client/ForestScreamSound.java`.
- Раз в 8–16 мин игры (настройка `forest.*`), после стартовой паузы «Режиссёра». Поверхность Верхнего мира, не пещера, не «мёртвый день».
- Место: 14–26 блоков, ≥110° от направления взгляда (за спиной), земля из `BlockTags.DIRT`, 2 блока воздуха без жидкости, ≥2 ствола (`BlockTags.LOGS`) в радиусе 4, нет блок-сущностей в радиусе 8, нет другого трупа в радиусе 8, чанк загружен (не грузим). Не нашлось — повтор через 30 с.
- Труп: обычная `Entity` (не `LivingEntity`) → «мёртвый день» её не убирает. Сохраняется в мире; с 4.6.1 возраст считается по `level.getGameTime()` (NBT `BornAt`), исчезает после 3 игровых дней, когда никого нет ближе 48 блоков — в том числе сразу после загрузки давно забытого участка. Сам лесной труп ставится только если `Director.worldChangesAllowed` (на сервере по умолчанию нет); звуки позади — всегда. Не кликается, не толкается.
- Рисунок: ванильный слой модели (`ModelLayers.SHEEP/SHEEP_FUR/COW/PIG/CHICKEN`), тело повёрнуто на бок (Z 90°), затемнено; поверх — тот же меш с `carcass_blood_overlay.png` (кровь в шкуре). Гор — кубики из атласа `carcass_gore.png` (мясо, кость, кишки, сгусток), лужи `carcass_blood.png`; всё генерирует `tools/gen_blood.py`. Раскладка детерминирована от UUID.
- С 4.6.0 раскладка — чистый код `anim/CarcassLayout.java` (без классов Minecraft): его вызывает и `CarcassRenderer` (через PoseStack), и симулятор `tools/animsim/CarcassSim.java` → `carcass_render.py` (ванильные модели из `carcass_models.py`, сверены с jar через javap; текстуры игры извлекает `extract_vanilla.py` из локального client.jar, в git не попадают). Кровь в шкуре — `carcass_soak_<kind>_<style>.png` на ванильной UV-развёртке, вес по расстоянию до раны (`gen_blood.py`). Атлас гора `carcass_gore.png` 128x16: мясо, кость, кишки, сгусток, срез шеи, срез ноги, полость, шерсть/перья; срезы — вырезка с рваным краем.
- С 4.5.0 четыре вида (`CarcassEntity.Style`, синхронизируется и сохраняется): DECAPITATED (голова рядом), GUTTED (голова на месте, мясо и рёбра на брюхе, кишки на земле), SCATTERED (туловище в центре, голова/ноги/крылья, мясо, кости, шерсть/перья в радиусе 3,8), DRAGGED (без головы, след 14 луж ~4 блока). Выбор случайный; `/anta carcass <вид> <стиль>`. В симуляторе не проверялось (он рисует только Наблюдателя).
- Звук (с 4.4.0 вместо крика): шаги или шорох со стороны трупа; плюс отдельно раз в 3–7 мин, пока рядом ≥2 ствола, — шаги/шорох сзади (±40°) без трупа. Пакет с мировым направлением → клиент держит источник в 3 блоках от игрока.
