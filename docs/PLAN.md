# План проекта «Anta»

## Видение
Антагонист выглядывает из-за угла: стоит за укрытием и наклоняется вбок так, что видна голова. Когда игрок поворачивается к нему — мгновенно прячется. Не нападает, не преследует, только смотрит. Для хоррор-сборок: создаёт ощущение, что за тобой следят.
