# Как тестировать

## Запуск
Вариант А — готовый jar: взять последнюю версию из папки «Anta - версии» на рабочем столе (с 4.0.0 файл называется `the1758645414-forge-1.20.1-<версия>.jar`, раньше — `anta-<версия>.jar`) и положить в папку `mods` Minecraft 1.20.1 с Forge 47.x (старую версию из `mods` удалить, иначе будет две копии мода).

**С 4.0.0 отладочные сообщения по умолчанию выключены.** Для проверки сначала `/anta debug on` (до выхода из мира) или `debugMessages = true` в `config/the1758645414-common.toml`. Полный чек-лист перед публикацией — `docs/release/PUBLISHING.md`. Пошаговый план тестов по блокам — `docs/TEST_PLAN.md`.
Вариант Б — из проекта:
1. В папке проекта: `gradlew.bat runClient` (или кнопка запуска в IntelliJ IDEA после импорта проекта).
2. Создать мир с **разрешёнными читами** (команды требуют уровень оператора 2).

## Команды
| Команда | Что делает |
|---|---|
| `/anta test` | Ищет укрытие по настоящим правилам (вне поля зрения), ставит светящегося наблюдателя |
| `/anta test any` | То же, но место может быть прямо перед игроком — удобно, чтобы сразу увидеть |
| `/anta test cave` | Засада в пещере: смотреть вдоль туннеля на поворот, ввести, идти вперёд — мелькнёт из-за угла |
| `/anta clear` | Убирает всех наблюдателей |
| `/anta react off` / `on` | Выключить / включить реакцию на взгляд (off — не прячется, можно рассмотреть) |
| `/anta react stare` / `slow` / `wait` / `return` / `snap` | С 4.2.0: каждый взгляд даёт эту реакцию («мозги», см. `docs/DIRECTOR.md`) |
| `/anta react random` | Реакцию снова выбирает «мозг» (обычная игра) |
| `/anta director` | Статус «Режиссёра»: сколько играете, когда следующее появление |
| `/anta director now` | Следующее появление — сразу (без ожидания); отвернитесь и ждите |
| `/anta director off` / `on` | Выключить / включить автоматические появления |
| `/anta debug on` / `off` | Включить / выключить отладочные сообщения (по умолчанию выключены, видны только операторам) |

С версии 2: если посмотреть ему в голову (≈25° от центра экрана), он прячется и исчезает; внизу экрана пишется «заметил — угол, дистанция». Первые 0,5 с после появления не реагирует.

Каждый `/anta test` убирает предыдущего наблюдателя.

## Что пишется в чат
`Spawned at X Y Z | dist … | lean right/left …° | light … | only head visible | out of view`
и статистика: сколько столбиков проверено, где можно стоять, сколько скрытых мест, сколько подходящих, время в мс.

Если места нет: `No cover found (...)` — по статистике видно, на каком шаге всё отсеялось.

## Чек-лист проверки
- [ ] Ровное поле без укрытий → места нет
- [ ] Деревня / дома → выглядывает из-за угла дома
- [ ] Лес → из-за ствола дерева (листва не считается укрытием)
- [ ] Пещера → из-за поворота пещеры
- [ ] Стоя в своём доме → не появляется за стеклом
- [ ] Наклон в правильную сторону (наружу из-за угла, а не в стену)
- [ ] Голова действительно видна с места игрока, а тело спрятано
- [ ] Время поиска приемлемое (желательно < 50 мс)

Результаты записывать в `docs/PLAN.md` → «Текущий статус».
